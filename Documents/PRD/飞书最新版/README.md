1. 每个模块一个文件，文件名建议格式：`<模块名>PRD.md`（如 `客户信用评估PRD.md`）。
2. 每次放入/更新文件时，在文件**第一行**标注同步日期，格式：`> 同步自飞书：YYYY-MM-DD`。
3. 本目录内容以飞书在线版为准；目录外的旧版 PRD（如 `../客户信用评估PRD_转录版.docx`）仅作历史参考，查询时优先使用本目录。
4. AI 回答 PRD 相关问题前，应先核对所引文件的同步日期；如明显过期，提醒用户重新 Copy 更新。
