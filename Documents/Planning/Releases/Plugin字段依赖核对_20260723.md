## 三、代码引用核对明细（按被删字段逐个列出）

### 1. `mcs_fca_quotaapp.mcs_applygenre`（信保额度类型）— ✅ Plugin 零引用

- 全部 Plugin、BPP Service 端均无引用；仅前端 JS `mcs_fca_quotaapp.js` 读取（JS 对缺失字段容错，不报错；新包导入后字段为 String 类型，JS 兼容）。
- **结论：可放心删除。**

### 2. `mcs_trade_stpayterm.mcs_buyergrade`（客户分类代码）— ⚠️ 2 个组件硬引用

| 组件 | 引用方式 | 字段缺失时行为 |
|------|---------|---------------|
| `TradeStPayTermValidationPlugin`（成交条件 Create/Update 重复校验） | 重复校验查询 `ColumnSet` 含 `mcs_buyergrade`；PreImage/Retrieve 回退读取 | **过渡期**新建/修改成交条件记录会抛异常（"entity doesn't contain attribute"） |
| `TradeStPayTermQueryService`（Custom API `mcs_QueryTradeStPayTerm`） | 结果查询 `ColumnSet` 含 `mcs_buyergrade`，按多选选项集匹配买家等级 | **过渡期**调用该接口会返回异常 |

### 3. `mcs_trade_stpayterm.mcs_creditgrade`（客户等级）— ⚠️ 同样 2 个组件硬引用

| 组件 | 引用方式 | 字段缺失时行为 |
|------|---------|---------------|
| `TradeStPayTermValidationPlugin` | 重复校验查询 `ColumnSet` 含 `mcs_creditgrade`；变更检测读取 | 同上，过渡期记录保存报错 |
| `TradeStPayTermQueryService`（Custom API `mcs_QueryTradeStPayTerm`） | `ColumnSet` 含 `mcs_creditgrade` | 同上，过渡期接口报错 |

> ⚠️ **同名不同字段不受影响**：`account.mcs_creditgrade`、`mcs_customermasterdata.mcs_creditgrade`（BppCallbackPlugin、CustomerMasterDataValidationPlugin 使用）、`mcs_fca_mdlconfig.mcs_creditgrade`（FCA 模型参数使用）是**各自实体上的独立字段**，不在本次删除范围，相关 Plugin 均正常。

### 4. `mcs_credit_scoringcard.mcs_listvalue`（定性项目值，若一并删除）— ⚠️ 2 个组件硬引用

| 组件 | 引用方式 | 字段缺失时行为 |
|------|---------|---------------|
| `CreditScoreCalculationPlugin` / `ScoreCalculator`（信用分计算） | 评分卡查询 `ColumnSet` 含 `mcs_listvalue`（代码兼容 String/Lookup 两种类型，但字段不存在会抛异常） | 过渡期信用分计算报错 |
| `CreditScoringCardValidationPlugin`（评分卡校验） | 按 `EntityReference` 读取 `mcs_listvalue` 并联查枚举值 | 过渡期评分卡保存报错 |

> ⚠️ **同名不同字段不受影响**：`mcs_credititem_value.mcs_listvalue`（String 类型，未变更）被 CofaceDataSyncPlugin、CustomerTagInitPlugin、CreditItemValueValidationPlugin、CofaceQualitativeMappingHelper 大量使用，该字段**不在删除范围**，均正常。
> 此字段属于「需核对」项：若生产上它已是 Lookup（与本次发版包一致），则**不需要删除**，也就没有影响。

### 5. `mcs_trade_stpayterm.mcs_nation` / `mcs_trade_pttype`（废弃 Lookup）— ✅ Plugin 零引用

- 全部 Plugin 代码已于 06-25 多选改造时切换到 `mcs_countries` / `mcs_trade_type`（Memo），对这两个旧 Lookup 无任何引用。
- **结论：可放心删除。**
