# 融资管理数据表定义（最终版 v1）

> 依据：《融资管理PRD.docx》 + 后台元数据核对 + 用户确认
> 说明：
> 1. 仅创建 3 个实体：`mcs_fsm_data`、`mcs_fsm_detail_data`、`mcs_fsm_resource`，放入解决方案 `entity_20260713`。
> 2. 附件与 BPP 审批信息复用现有机制，不新建实体。
> 3. PRD 中写为“文本”但实际为 Lookup 的字段，已统一修正为 Lookup。
> 4. 客户编码保持文本，客户名称改为 Lookup → `mcs_customermasterdata`。
> 5. 本位币为 USD；带 `USD` 字样的字段使用 `Decimal` 直接存储 USD 数值；其他金额字段使用 `Money`，币种 = `mcs_fsm_currency`。
> 6. 融资资源管理表中的金融产品多选字段使用多选选项集（`MultiSelectPicklist`），银行产品编码 1-11，保险产品编码 101-104；前端按机构类型筛选显示。

## 八、附件与 BPP 审批复用说明

### 8.1 附件

- 不复用 PRD 中的 `mcs_fsm_files` 实体。
- 复用三一通用上传组件（`mcs_InitUploadFile` / `mcs_CommitUploadFile`）。
- 附件元数据通过现有文件服务/附件实体管理，不在融资管理表中存附件 ID 字段。
- 如需在表单展示附件，通过通用 Uploader 组件嵌入表单页签实现。

### 8.2 BPP 审批

- 不复用 PRD 中的 `mcs_fsm_approve` 实体。
- 复用现有 BPP 框架：
  - 提交审批：调用现有 `mcs_bppstartapi`（或业务提供的融资专用 BPP 接口）。
  - 审批回调：由现有 BPP Consumer 处理，回写审批状态到 `mcs_fsm_data` 的扩展字段（如需要，可在本阶段增加少量状态字段，但不再新建审批信息实体）。
