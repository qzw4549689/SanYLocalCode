## 一、模块概述

### 1.1 业务目标

以工厂端三一为核心主体，对出口贸易客户进行信用额度授予、评估、监控和调整。厂端授信是客户赊销交易场景在外部融资、中信保授信之后的补充授信手段。

融资优先级：**外部融资 > 中信保赊销 > 厂端授信**

### 1.2 功能模块划分

| 模块 | 实体显示名（中文） | 实体逻辑名 | 核心功能 |
|------|------------------|-----------|---------|
| 授信模型版本 | 厂端授信模型版本表 | `mcs_fca_mdlversion` | 维护授信计算模型版本 |
| 授信参数配置 | 厂端授信模型参数配置表 | `mcs_fca_mdlconfig` | 配置模型系数和历史基准额度 |
| 授信模型计算 | 厂端授信模型计算表 | `mcs_fca_proc` | 执行不予授信校验、模型计算、生效启用 |
| 授信额度主档 | 厂端授信额度表 | `mcs_fca_quota` | 存储客户生效额度和余额 |
| 额度调整申请 | 厂端授信额度申请单表 | `mcs_fca_quotaapp` | 人工调整额度并走 BPP 审批 |
| 额度台账 | 厂端授信额度动态调整管理台账表 | `mcs_fca_records` | 记录额度变动流水 |
| 客户标签扩展 | 客户主数据表 | `mcs_customermasterdata` | 复用/确认黑名单、不予授信标签 |

> **注意**：本模块**不新建**独立的附件实体。额度调整申请附件使用现有通用上传组件（`mcs_/CommonCore/Html/Uploader.html`），附件统一存储在 `mcs_customer_file`（客户资信附件表）。

```csharp
public static class CustomerCategoryService
{
    /// <summary>
    /// 根据客户主数据字段计算客户分类
    /// </summary>
    public static string CalculateCategory(
        int? accountType,       // 客户类型：1=个人
        int? accountCategory,   // 客户类别
        int? accountLevel,      // 大客户级别
        int? dealerLevel)       // 经销商分级
    {

        }
        return accountLevel switch { 4 => "S", 3 => "A", 2 => "B", _ => "C" };
    }
}
```

**步骤 3：引用 JS 初始化上传组件**

在 `mcs_fca_quotaapp` 表单库中引用初始化函数（可复用 `mcs_credit_record.js` 中的 `initAttachmentTab` 逻辑，或新建 `mcs_fca_quotaapp.js`）：

```javascript
function initAttachmentTab(executionContext) {
    var formContext = executionContext.getFormContext();
    var accountAttr = formContext.getAttribute("mcs_accountid");
    if (!accountAttr || !accountAttr.getValue()) return;

    var accountValue = accountAttr.getValue()[0];
    var accountId = accountValue.id;
    var accountName = accountValue.name;

    var uploaderControl = formContext.getControl("mcs_fca_quotaapp_uploader");
    if (!uploaderControl) return;

    // 等待 iframe 加载完成
    var uploaderObj = uploaderControl.getObject();
    if (uploaderObj && uploaderObj.contentWindow && uploaderObj.contentWindow.initUploaderContext) {
        uploaderObj.contentWindow.initUploaderContext({
            entityName: "mcs_customer_file",
            relatedEntityName: "account",
            relatedEntityId: accountId,
            relatedEntityDisplayName: accountName,
            extraData: {
                // 上传成功后，把当前申请单 ID 也写入 mcs_customer_file.mcs_fca_quotaappid
                mcs_fca_quotaappid: formContext.data.entity.getId()
            }
        });
    }
}
```

## 八、风险点与注意事项

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 客户分类逻辑与成交条件样板库不一致 | 计算错误 | 统一服务类，业务侧确认 |
| 月度在外货款数据缺失或延迟 | 逾期调整不准确 | 增加数据缺失兜底逻辑 |
| 多币种汇率转换精度问题 | 额度计算偏差 | 统一货币转换服务，保留计算日志 |
| 字段逻辑名与 PRD 笔误冲突 | 字段不匹配 | 按 PRD 实施同时标注修正点 |
| 通用上传组件未正确初始化 | 附件无法上传 | 复用信用评估记录成熟配置 |
| 额度调整申请并发提交 | 余额计算冲突 | 使用乐观锁或事务控制 |
| BPP 审批状态同步失败 | 额度状态不一致 | 增加重试机制和异常通知 |
| 历史基准额度年度更新 | 配置数据维护 | 提供批量导入模板 |
