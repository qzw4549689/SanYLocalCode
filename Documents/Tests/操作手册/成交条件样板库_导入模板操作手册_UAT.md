# 成交条件样板库 导入模板操作手册（UAT 测试版）

> **适用环境**：UAT（`https://sany-uat.crm5.dynamics.com`）
> **适用对象**：成交条件配置人员（UAT 测试）
> **版本**：V1.0（2026-07-24）

---

## 一、下载标准模板

1. 登录 UAT，进入「**成交条件基线库**」列表页；
2. 点击工具栏的「**Excel 模板**」按钮（见下图 1）；
3. 在下拉菜单的「Excel 模板」区域，点击「**成交条件样板库_导入模板_V1.0****（见下图 1 红框）；

![图1：Excel 模板按钮与模板选择](images/trade_import_step1.png)

4. 在弹出的二级菜单中，点击「**下载 成交条件样板库_导入模板_V1.0**」（见下图 2 红框）；

![图2：下载模板](images/trade_import_step2.png)

5. 浏览器会下载一个 `.xlsx` 文件。

> ⚠️ **注意**：刚下载下来的文件里**自带系统中已有的数据**（这是系统的默认行为，不是模板做错了）。请按下一步清空后再使用。

---

## 二、清空数据，制作自己的空模板（只需做一次）

1. 打开刚下载的 Excel 文件；
2. **保留第 1 行表头不动**（包括 A/B/C 列的「（不要修改/删除）」标记列）；
3. **选中第 2 行到最后一行的所有数据行，整行删除**；
4. 清空后的样子应与下图 3 一致：只有蓝色表头，下面全是空行；

![图3：清空数据后的空模板](images/trade_import_step3.png)

5. 另存为：`成交条件样板库_导入模板_空模板_V1.0.xlsx`。

✅ **以后每次导入数据，都使用这份清空后的模板**，不需要再重复下载。

> 🚫 **绝对不能动的内容**（动了会导致导入失败）：
> - A/B/C 三个「（不要修改/删除）」列；
> - 第 1 行表头的文字、顺序；
> - 工作表中隐藏的元数据（不要删除任何工作表）。

## 三、填充数据规则

| 列 | 填写说明 |
|---|---|
| 事业部 | 填写事业部**完整名称**，必须与系统基础数据一字不差（建议直接从本文第四节表格复制） |
| 大区/子公司 | 填写大区/子公司**完整名称**，必须与系统基础数据一字不差；选定后系统会按大区自动校验所属事业部 |
| 国家名称 | 填写国家名称（如 `中国`、`南非`）；**多个国家用英文逗号 `,` 分隔**（如 `中国,南非`）；名称必须与系统国家基础数据一致 |
| 产品分类名称 | 填写产品分类名称（如 `泵车`）；**多个用英文逗号分隔**（如 `泵车,电动牵引车,燃油牵引车`） |
| 客户等级 / 客户分类 | 按系统选项填写（如 `A1`；`S, A, B, C, I` 中之一） |

**通用规则**：

1. **名称必须精确**：所有名称类字段（事业部/大区/国家/产品分类）必须与系统里的基础数据**完全一致**，多一个空格、错一个字都会被导入拒绝，并报错「无法识别的xx名称【yyy】」；
2. **NA 表示通配**：某列不限制时填 `NA`（或不填）；
3. **重复数据会被拦截**：同一事业部下，大区/国家/产品分类有交集的记录不允许重复导入，会提示「存在有重复记录，需核查！」；
4. **标准条件编码不用填**：由系统自动生成（TC + 日期 + 序号）。

## 五、导入与结果检查

1. 回到「成交条件基线库」列表页，使用「**导入数据**」功能上传填好的模板；
2. 导入完成后**逐条打开记录检查**：
   - 表单上的「国家」「产品分类」多选控件应**正常显示所选内容**（如果空白说明名称没匹配上，请核对名称后重新导入）；
   - 「事业部」「大区/子公司」应正确显示且互相对应；
3. 如导入有失败行，在导入向导的**失败记录**中可下载错误明细，常见错误对照：

| 报错 | 原因 | 处理 |
|---|---|---|
| 无法识别的国家名称【xxx】 | 国家名称与系统基础数据不一致 | 核对名称（注意空格/错别字），改后重导 |
| 无法识别的产品分类名称【xxx】 | 产品分类名称不一致 | 同上 |
| 存在有重复记录，需核查！ | 同事业部下维度与已有记录有交集 | 删除重复行或调整维度 |
| 首付款比例必须在 0% 到 100% 之间 | 首付款比例超范围 | 改为 0~1 之间的小数 |
| 账期（天）必须是 0 或 30 的倍数 | 账期不合规 | 改为 30 的倍数 |
