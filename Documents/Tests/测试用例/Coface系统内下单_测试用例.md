> **版本**：V1.0
> **日期**：2026-08-10
> **关联文档**：`Documents/Planning/Coface系统内下单/Coface系统内下单实施方案.md`（V2.0）
> **适用环境**：DEV1 / UAT（UAT 发布后执行回归）
> **说明**：本用例替代《测试用例总集》中与「Coface 下单/进入数据集成」相关的旧口径，用于 Coface 系统内下单功能的专项测试与端到端回归。

## 1. 功能变化摘要（相对旧流程）

| 对比项 | 旧流程（改造前） | 新流程（本次改造后） |
|---|---|---|
| Coface 下单方式 | 业务在 Coface 平台线下人工下单，D365 只查已有订单 | D365 内「关联客户代码」阶段点击【Coface 下单】按钮，系统内完成下单 |
| 下单链路 | 无 | 点击推进式状态机：调查单 → URBA 监控单 → Report 单，每次点击只做一件事 |
| 订单未就绪时进入数据集成 | 不阻断，指标填缺失值继续（信用分失真） | **前端硬阻断**（按 PRD）：提示未就绪，停留「关联客户代码」阶段 |
| 订单状态跟踪 | 无字段 | 新增 3 个字段：Coface 下单状态 / Coface 下单信息 / Coface 下单时间 |
| 防重复扣费 | 无 | 每阶段先查已有订单再下单，复用优先（即时报告 → 已有订单 → 新下单） |

**Coface 下单状态（6 个值）**：

| 值 | 中文 | 含义 |
|---|---|---|
| 0 | 未下单 | 初始状态 |
| 1 | 调查单已提交 | 公司未被 Coface 识别，已提交免费调查单 |
| 2 | URBA已下单待就绪 | URBA 监控单已下，等待数据就绪 |
| 3 | Report已下单待就绪 | Report 单已下，等待报告出具（约 6-7 个工作日） |
| 4 | 已就绪 | 可进入「内外部数据集成」 |
| 5 | 下单失败 | 接口/参数异常，可重试（重试走"查已有订单"分支，不重复扣费） |
