=== D365 实体管理工具 ===
目标环境: https://pre.crm5.dynamics.com
用法:
  dotnet run create <实体定义文件.json>   - 从JSON文件创建实体和字段
  dotnet run check <解决方案名>           - 检查解决方案中的实体
  dotnet run add <实体名> <解决方案名>    - 添加实体到解决方案
  dotnet run remove <实体名> <解决方案名> - 从解决方案移除实体
  dotnet run publish [实体名]             - 发布指定实体（禁止无参数全局发布）
  dotnet run delete-field <实体名> <字段名> - 删除字段
  dotnet run list-fields <实体名>         - 列出实体所有字段
  dotnet run update-entity-displayname <实体名> <中文> [英文] - 更新实体显示名称（多语言）
  dotnet run set-entity-label <实体名> <中文> <英文> - 设置实体显示名称（Web API PUT，中英双语）
  dotnet run update-field-displayname <实体名> <字段名> <中文> [英文] - 更新字段显示名称（多语言）
  dotnet run set-field-label <实体名> <字段名> <中文> <英文> - 设置字段显示名称（Web API PUT，中英双语）
  dotnet run update-field-required <实体名> <字段名> <true|false> - 更新字段必填性
  dotnet run update-field-range <实体名> <字段名> <最小值> <最大值> - 更新 Money 字段取值范围
  dotnet run update-field-default <实体名> <字段名> <默认值> - 更新字段默认值（Picklist/Decimal）
  dotnet run update-field-description <实体名> <字段名> <描述> - 更新字段描述
  dotnet run get-entity-displayname <实体名> - 查询实体显示名称（诊断）
  dotnet run export <解决方案名> <路径>    - 导出解决方案为 ZIP
  dotnet run export-translations <解决方案唯一名> <输出ZIP路径> - 导出 translations ZIP（D365 标准翻译导出）
  dotnet run import-translations <translations ZIP 路径> - 导入 translations ZIP（D365 标准翻译导入）
  dotnet run create-credit-items          - 创建评分项目测试数据(22条)
  dotnet run query-credit-item-descs      - 查询评分项目说明(mcs_itemdesc)
  dotnet run create-qualitative-enums     - 创建定性枚举值测试数据(30条)
  dotnet run fix-qualitative-enums-mapping - 整理国别/行业风险枚举值为三一标准L/M/H/O
  dotnet run fix-percentage-scoring-cards - 修复百分比/比率类评分卡区间量纲（NetProfit/DebtRatio/LatePaymentIndex）
  dotnet run cleanup-orphan-sectors-scoring-cards - 删除 Sectors 评分卡中无法匹配枚举值的孤儿记录
  dotnet run dedup-credititem-values      - 清理 mcs_credititem_value 重复记录（保留最早，迁移引用）
  dotnet run update-credit-record <scoreid> [status] - 更新信用评估记录状态(默认→12)
  dotnet run simulate-bpp-callback <scoreid> [Approved|Rejected|Withdrawn|Abandoned] - 模拟BPP回调触发审批逻辑
  dotnet run simulate-fca-bpp-callback <申请单编号|ID> [Approved|Rejected|Withdrawn|Abandoned] - 模拟BPP回调触发厂端授信额度调整申请审批逻辑
  dotnet run test-fsm-bpp               - 融资管理BPP回调Plugin全场景验证（立项通过/方案通过/方案驳回/撤回）
  dotnet run test-tradestpayterm          - 测试成交条件样板库 Plugin（自动编号/校验/状态流转）
  dotnet run query-plugin-steps <类名>    - 查询已注册的 Plugin Steps
  dotnet run query-plugin-namespace <前缀> - 查询命名空间下所有 Plugin Steps
  dotnet run register-plugin-image <StepId> <Image名称> <Image别名> <字段列表> - 为Plugin Step注册PreEntityImage
  dotnet run fix-dev-scoring-cards        - 重建DEV评分卡配置（补全mcs_itemid/mcs_datatype/mcs_cardname）
  dotnet run fix-scoring-card-typeids     - 批量修复评分卡配置(mcs_typeid)根据mcs_credititem.mcs_group
  dotnet run remove-duplicate-scoring-cards - 删除DEV1评分卡配置重复记录
  dotnet run add-overdue-model-sa         - 为SA老客户评分卡补入OverdueModel(预计损失率)30分配置
  dotnet run export-webresource <名称> <路径> - 导出 WebResource 内容
  dotnet run update-webresource <名称> <文件路径> - 更新 WebResource 内容
  dotnet run list-webresources [前缀]    - 列出 WebResource（默认前缀 ms_languagefile）
  dotnet run list-form-webresources <实体> - 列出实体主窗体引用的 JS WebResource
  dotnet run deploy-webresource <名称> <文件路径> <类型> [显示名] - 创建或更新 WebResource 并发布
    类型: 1=HTML, 2=CSS, 3=JScript, 4=XML, 5=PNG, 6=JPG, 7=GIF, 8=XAP, 9=XSL, 10=ICO, 11=SVG, 12=RESX
  dotnet run add-webresource-to-solution <WebResource名称> <解决方案唯一名> - 将 WebResource 加入解决方案
  dotnet run test-common                  - 隔离测试 D365ToolCommon 共享库（自动创建/删除测试实体）
  dotnet run cleanup-test-common          - 仅清理 D365ToolCommon 测试实体
  dotnet run clear-account-credit-fields <客户名称> - 清空客户及客户主数据上的8个信用字段（用于测试）
  dotnet run check-fix-masterdata <客户名称> - 检查并修复客户主数据上的基础字段
  dotnet run set-masterdata-isdd <客户名称> <true|false> - 设置客户主数据重点尽调标志
  dotnet run set-masterdata-creditvalid <客户名称> <true|false> - 设置客户主数据信用评估有效状态
  dotnet run show-profile <客户名称> - 查询客户画像关键属性
  dotnet run sync-profile <源客户名称> <目标客户名称> - 同步客户画像关键属性（用于测试）
  dotnet run simulate-approval <客户名称/编码> <评估编码> - 模拟审批通过，将信用分/等级回写客户主数据
  dotnet run set-countrycode <客户名称/编码> <国家代码> - 设置客户主数据国家代码（用于测试）
  dotnet run set-cofaceid <评估编码> <cofaceId> - 设置信用评估记录的科法斯客户代码
  dotnet run export-coface-data <输出目录>  - 导出 Coface NACE映射和汇率配置数据
  dotnet run import-coface-data <数据目录>  - 导入 Coface 基础数据到当前环境
  dotnet run diagnose-credit-record <评估编码> - 诊断 credit record 数据集成问题
  dotnet run list-entities <前缀>        - 列出指定前缀的实体
  dotnet run create-test-salesorder <客户名称> - 为客户创建一条测试销售订单（用于老客户判定）
  dotnet run create-credit-testdata <客户名称> - 为客户创建信用评估测试数据（销售订单 + 逾期在外货款）
  dotnet run create-credit-record <客户名称> - 为客户创建一条新的信用评估记录
  dotnet run list-app-actions [前缀]       - 列出 App Action (Modern Command Bar 按钮)
  dotnet run list-security-roles [关键字]  - 列出安全角色
  dotnet run list-custom-apis [关键字]     - 列出 Custom API（含参数与响应属性）
  dotnet run check-solution-customapi <解决方案名> - 检查解决方案包含的 Custom API
  dotnet run deploy-tradestpayterm-api <DLL路径> - 部署成交条件样板库查询 Custom API
  dotnet run delete-tradestpayterm-api          - 删除成交条件样板库查询 Custom API
  dotnet run deploy-fcaquota-api <DLL路径> [Plugin类名] - 部署厂端授信余额调整 Custom API
  dotnet run delete-fcaquota-api                - 删除厂端授信余额调整 Custom API
  dotnet run test-fcaquota-api <客户编码> <金额> <环节> <动作> [合同编码] [订单编码] - 测试厂端授信余额调整 Custom API
  dotnet run test-tradestpayterm-api <buId> <subId> <countryCode> <prdGroupId> <buyerCode> - 测试成交条件样板库查询 Custom API
  dotnet run query-tradestpayterm-samples [条数] - 查询成交条件样板库样本数据
  dotnet run create-tradestpayterm-testdata    - 创建一条生效的成交条件样板库测试数据
  dotnet run rebuild-tradestpayterm-grade-fields [环境] - 重建成交条件样板库客户分类/客户等级为多选选项集
  dotnet run recreate-fca-decimal-fields  - 将 mcs_fca_proc 的 mcs_modelgrant/mcs_initigrant 从 Money 重建为 Decimal
  dotnet run query-optionset <实体名> <字段名>       - 查询选项集字段的标签
  dotnet run list-transaction-currencies   - 列出 D365 标准交易货币及汇率
  dotnet run test-coface-exchange-rate [币种列表] - 测试 Coface 汇率读取与转换（默认 USD,EUR,CNY,JPY,VND,XXX）
  dotnet run test-upload-api <文件路径> <accountId> [mcp|mcs|all] - 测试上传 Custom API
  dotnet run fix-form-lookup <实体名>    - 修复主窗体 Lookup 控件 classid
  dotnet run query-contracts [accountId]  - 查询 mcs_contract 合同数据分布（只读诊断）
  dotnet run query-contract-products <accountId> - 查询客户合同明细产品字段（只读诊断）
  dotnet run query-optionset-labels <实体名> <字段名> [langId] - 查询选项集本地化标签
  dotnet run update-optionset-labels <实体名> <字段名> <labels.json> [langId] - 更新选项集标签
  dotnet run create-credit-profile-fields  - 创建客户画像所需缺失字段（mcs_blacklist/mcs_creditgrant）
  dotnet run list-number-configs [实体名] - 查询系统自动编号配置（只读）
  dotnet run create-number-config <实体名> <属性名> <前缀模板> <数字模板> <序列号长度> [序号开始] [使用序列号服务true|false] - 新增自动编号配置
  dotnet run delete-number-config <实体名> <属性名> - 删除指定实体的自动编号配置
  dotnet run test-number-config <实体名> [属性名] - 创建并删除一条测试记录验证编号生成
  dotnet run register-number-config-step <实体名> - 为实体注册通用自动编号 Plugin Step
  dotnet run check-release <清单.json> [--with-fields] - 通用发版 Solution 归属自检（只读，--with-fields 逐字段核对）
  dotnet run check-solution-coverage <源Solution唯一名> [实体包Solution唯一名] - 以源 Solution 为真相源，核对组件是否已分布到发版包（只读）
  dotnet run list-solution-components <Solution唯一名> - 列出 Solution 全部组件（类型+名称+ObjectId，只读）
  dotnet run query-sitemap [sitemapId|名称关键字] - 查询 SiteMap 记录、App↔SiteMap 对应关系及解决方案分层（只读；单个时导出 XML 到 /tmp）
  dotnet run query-app-components <App名称关键字> [实体名前缀] - 列出 App 包含的组件（只读）
  dotnet run list-workflows [关键字] - 列出工作流/BPF 流程定义（只读）
  dotnet run add-solution-component <componentType> <objectId> <Solution唯一名> - 通用加组件（写操作，需用户明确授权）
  dotnet run check-solution-deps <Solution唯一名1> [Solution唯一名2] ... - 模拟导出时的缺少必需组件依赖检查（只读）
